# 📝 Notes App

A simple and professional Notes App built with React.js for creating and managing personal notes.

## Features

- Add notes
- Edit notes
- Delete notes with confirmation
- Search notes
- Save notes in Local Storage
- Responsive design
- Masonry-style layout
- Smooth CSS animations
- Dark and Light mode

## Technologies

- React.js
- JavaScript
- CSS3
- HTML5
- Local Storage
- Vite

## Run Locally

```bash
npm install
npm run dev
